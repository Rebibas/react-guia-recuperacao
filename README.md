
# React em Prática — Guia Interativo

Projeto desenvolvido para a avaliação prática de recuperação de React.

## Sobre o projeto

O projeto é um guia de estudos que apresenta conteúdos importantes sobre React, JavaScript e desenvolvimento web.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite

## Funcionalidades

- Oito cards educativos.
- Exemplos práticos de programação.
- Explicações de erros comuns.
- Marcação de conteúdos revisados.
- Contador de conteúdos revisados.
- Cadastro de dúvidas.

## Como executar o projeto

1. Clone o repositório.
2. Abra a pasta do projeto no terminal.
3. Execute npm install.
4. Execute npm run dev.
5. Abra o endereço informado no terminal.
